# Sonsuz Nefes Alma Simülasyonu

Bu repository, insanlığın en temel ihtiyacı olan nefes almayı simüle eden dünyanın en önemli yazılımıdır.

## Neden Bu Proje?

Çünkü nefes almak sandığınızdan daha karmaşıktır. Bu simülasyon, bir sonraki nefesinizi hesaplar. Hesaplamayı bitirmez. Asla.

## Nasıl Çalıştırılır?

```bash
python nefes_al.py
```

**Uyarı:** Bu program sonsuza kadar çalışabilir. Ctrl+C ile durdurabilirsiniz ama gerçek hayatta bu seçenek yoktur.

## Özellikler

- Gerçekten nefes alır (simüle eder)
- Rastgele oksijen seviyeleri
- Arada kriz çıkarır
- Hiç bitmez

## Lisans

Bu kod özgürce kullanılabilir. Nefes almak da özgür olmalıdır.
